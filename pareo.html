♟️ Pareo Integral

Emparejamientos de torneos de ajedrez con el Sistema Holandés de FIDE, resultados y desempates. Gratis, sin cuenta y en tu computadora.

Mis torneos

Lo que escribes queda guardado solo en este navegador. Para pasarlo a otra computadora o tener una copia, baja el archivo del torneo en «Archivos».

Datos del torneo

Sistema

El sistema ya no se puede cambiar: hay rondas emparejadas.

Puntos

Desempates, en orden

Se aplican uno detrás del otro, según el reglamento C.07 de FIDE (versión 2026). Los que usan el Elo necesitan el Elo de todos los jugadores.

    Agregar un jugador

    Pegar una lista de jugadores

    Uno por línea: Nombre; Elo; Título; Federación; ID FIDE. Sirve copiar las columnas de una hoja de cálculo (con tabuladores también).

    Inscritos (0)

    El número de cada uno sale del orden inicial de FIDE: Elo, título y nombre.

    Todavía no hay nadie inscrito.

    Clasificación

    Tabla cruzada

    En cada ronda: el número del rival, el color (b blancas, n negras) y el resultado. «+» y «−» son partidas no jugadas.

    Este torneo

    El TRF es el archivo que FIDE pide para el informe de Elo, y el que leen los demás programas de emparejamiento.

    Abrir un torneo

    Sirve el TRF de Swiss-Manager, Vega u otro programa: se siguen emparejando las rondas que faltan.

    Comprobador de emparejamientos

    Pega un TRF (de cualquier programa) y se vuelve a emparejar cada ronda con el Sistema Holandés para ver si coincide con la que se jugó.

    Generador de torneos al azar

    Arma un torneo entero con resultados al azar, emparejado con el Sistema Holandés. Con la misma semilla sale siempre el mismo torneo: sirve para comparar programas.

    Con qué está hecho

    Los emparejamientos los calcula bbpPairings (Jeremy Bierema, licencia Apache 2.0), el motor del Sistema Holandés que usan programas avalados por FIDE, compilado para correr en tu navegador.

    Los desempates siguen el C.07 de FIDE (versión 2026) y están comparados con chesspairing (Gert Nutterts, licencia Apache 2.0).

    Pareo Integral todavía no tiene el aval de FIDE.
